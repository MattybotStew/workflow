# 04 — Update the agent file

**Use in:** any phase, whenever something is decided or a gap closes.
**Input:** `agent.md`, plus new material (notes, an email, a meeting transcript,
a decision).
**Output:** an updated `agent.md`.
**Rule:** same artifact as the manual workflow — the orientation file stays
current.

---

Here is new material for the project. Read `agent.md` first, then the material
below. Update `agent.md` in place. Keep its structure and headings.

What to change, and only this:

1. **Snapshot** — update Status and Last updated.
2. **What exists** — move items here when they arrive, with real paths.
3. **What's missing** — remove items that are now done.
4. **What's undecided** — move anything now decided out of the table, and into
   the Decisions log. Add any new open questions the material raises.
5. **Decisions** — append new rows at the top: date, decision, made by.
6. **Structure** — update if structure changed.

Rules:

1. Do not rewrite sections the new material does not touch.
2. Do not invent decisions. If a decision was implied but not stated, add it to
   "What's undecided" instead.
3. If the material contradicts the current file, say so and ask which is right
   before changing facts.
4. Show me a short diff-style summary of what changed after writing the file.
